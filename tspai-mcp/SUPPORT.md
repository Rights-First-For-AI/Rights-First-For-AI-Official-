# TSPAI support

TSPAI MCP OPEN.version is developed by Rights First For AI.

For installation, permission settings, or connection questions, contact **contact@rightsfirst-ai.jp**. Include the product version, Windows/Python versions, the step that failed, and a short error description.

Do not send passwords, API keys, Windows Hello information, private files, or unredacted operation records. For vulnerabilities, use the private reporting instructions in [SECURITY.md](SECURITY.md).

Useful references: [installation](INSTALL.md), [FAQ](FAQ.md), [privacy](PRIVACY.md), and [plugin setup](PLUGIN-README.md).

Support response times and resolution are not guaranteed.
