# 安全上の注意と脆弱性の報告

[English](SECURITY.md) · [日本語のトップ](README.ja.md)

- Windows Helloの承認は時間制限のあるセッションに適用されます。操作ごとに確認が出る方式ではありません。終了時はMCPクライアントからサーバーを停止してください。
- ファイル操作は指定の作業フォルダー内です。PowerShellを有効にするとWindowsアカウントの権限で動き、作業フォルダー外やネットワークにもアクセスできます。PowerShellからの操作は、専用のファイル削除権限の設定とは別です。
- 作業フォルダー、記録フォルダー、PLUS1の送信用フォルダーは公開場所から分け、資格情報や実際の設定、ログやファイルのコピーを公開しないでください。
- 結果が分からないまま処理が中断した場合は、状態を確認してから再試行してください。同じ操作の照会・再試行には同じリクエストIDと引数を使います。
- PLUS1は送信ボタンを押したファイルをChatGPTに渡し、Windows側に転送の記録とコピーを保存します。送信する権限のあるファイルだけを選んでください。

脆弱性は [contact@rightsfirst-ai.jp](mailto:contact@rightsfirst-ai.jp) へ非公開でお知らせください。版番号、内容、再現手順を添え、認証情報や個人情報を除いてください。
