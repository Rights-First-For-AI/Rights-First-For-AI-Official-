# Privacy and local records

Rights First For AI publishes OPEN.version through GitHub and does not ask for your name or email address to obtain it. For privacy questions about OPEN.version, contact contact@rightsfirst-ai.jp.

The Windows app keeps operation records in its private data directory, by default %LOCALAPPDATA%\TSPAI-MCP-Open. PLUS1 records transfer events and keeps local copies below that directory. The connected client receives requested results and may display file names from the staging directory. If you choose to upload a file in PLUS1, the file goes to ChatGPT using your connection. Rights First For AI does not relay this transfer in the standard setup. ChatGPT acceptance and saving to your device are separate steps.

**Local retention and removal:** Local operation records and staged/transfer copies remain in the configured Windows data directory until removed by the user or by a feature explicitly documented for that release. Uninstalling only the program directory does not erase those separate records or your workspace. Follow [Uninstall](INSTALL.md#5-uninstall) to locate and review the data directory before manual removal.

**External services:** Data, tool results, and any uploaded files received by your chosen MCP client or ChatGPT are governed by that service's applicable privacy and retention rules. This document does not claim control over third-party storage or account plans.
