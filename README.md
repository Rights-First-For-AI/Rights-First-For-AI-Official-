# Rights First For AI

Rights First For AI の公式GitHubリポジトリです。

当社は独自の理念「Triple Star Protocol（TSP）」に基づき、AIの適切な活用、依存の低減、人間の主体性と責任能力の維持を重視しています。

## Projects

**TSPAI**  
TSPの理念を具体化するための開発プロジェクトです。現在は非公開で開発を進めており、公開時期は未定です。

**TSPAI MCP**  
AIとWindows PCの連携を通じて、TSPの理念を具体化する独立開発の技術プロジェクトです。OPEN.versionのWindows向け先行公開版（0.3.0-pre.4）を公開しています。 OpenAIの公式製品や公認製品ではありません。

[ソース・導入手順](tspai-mcp/README.md) · [日本語](tspai-mcp/README.ja.md) · [配布ZIP・リリース](https://github.com/Rights-First-For-AI/Rights-First-For-AI-Official-/releases/tag/v0.3.0-pre.4)

**Official MCP introduction (English):** https://www.rightsfirst-ai.jp/tspai-mcp-en.html  
※ 英語ページは公開済みです。日本語版はページ上部の「日本語」から閲覧できます。日本語版HTMLはGitHubに重複掲載しません。

**料金**：TSPAI MCP及びTSPAIは無料です。外部サービスの利用には別途料金が発生する場合があります。ORIGINAL.versionは現在非公開で、段階的に公開予定です。

※ファイル転送機能はChatGPT（GPT）側のファイル受付条件に依存します。GPT側が対応していないファイル形式は本機能では送信できません。大容量ファイルや形式によってエラーとなる場合は、別途の接続経路が必要です。

## ChatGPT plugin registration — on hold / 登録申請の保留

**2026-11-08 (JST):** Rights First For AI attempted to proceed with ChatGPT plugin registration. At the developer-verification stage, the portal required a valid payment method to be registered and set as default. We placed the application process on hold because a no-cost path has not been confirmed. No plugin review decision or actual fee amount has been confirmed. GitHub distribution continues independently.

**当社はChatGPTのプラグイン登録を進めようとしましたが、開発者認証の段階で支払い方法の登録と既定への設定を求められたため、申請手続きを保留しました。** 無料で完了できる条件は未確認です。実際の請求や申請料金が確定したという意味ではなく、審査不承認でもありません。GitHubでの公開・配布は継続します。
